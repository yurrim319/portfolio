# 개발 포트폴리오 템플릿

> Tool Development 섹션에 들어갈 항목을 정리할 때 쓰는 양식입니다.
> 아래 두 가지 템플릿 중 상황에 맞는 걸 골라 쓰면 됩니다.
>
> - **템플릿 A**: 툴 1개가 명확히 독립적인 경우 (예: 인하우스 자동화 툴)
> - **템플릿 B**: 하나의 앱/프로젝트 안에 여러 파트가 얽혀있는 경우 (예: VVWorld 클라이언트 작업)

---

### [툴 이름]

**Overview**
(이게 뭐고, 왜 만들었는지 1~2문장)

**문제 상황 (Before)**
(이 툴이 없었을 때 뭐가 불편했는지, 가능하면 수치로)

**해결 과정 (How)**
(어떤 기술로 접근했는지, 왜 그 방법을 선택했는지)

**결과 (After)**
(Before 대비 뭐가 좋아졌는지, 가능하면 수치로)

**스크린샷 / 데모**
(UI 캡처, gif, Before-After 비교 이미지 — 있으면)

## 작성 체크리스트
- [ ] Overview는 1~2문장으로 짧게 썼는가
- [ ] 문제 상황에 가능하면 숫자를 넣었는가 (없으면 "반복 작업", "휴먼에러" 등 상황 설명으로 대체)
- [ ] 해결 과정에 "왜 이 방법을 선택했는지" 판단 근거가 들어갔는가
- [ ] 결과에 Before 대비 변화가 명확히 드러나는가
- [ ] (템플릿 B) 파트를 3~4개 이하로 정리해 너무 잘게 쪼개지 않았는가
